# RAKA × ALYA Web App

Versi PWA dari Raka × Alya Prompt Library.

## Agar punya alamat web tetap
Upload seluruh isi folder ini ke hosting static seperti GitHub Pages, Cloudflare Pages, atau Netlify. Setelah terbit, gunakan URL HTTPS tersebut sebagai alamat tetap. Jangan membuka `index.html` dari folder Download jika ingin fitur PWA/install/offline aktif.

## Data
Prompt tambahan/edit/hapus tetap disimpan di `localStorage` browser pada alamat web tersebut. Fitur Backup/Restore tetap tersedia.
